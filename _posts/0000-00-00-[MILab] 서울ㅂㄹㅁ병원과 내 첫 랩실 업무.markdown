# Work
---
## Data Preprocessing
선배님들께서 업무에 필요한 자료를 공유해주셨다.  
csv 파일과 특이한 확장자 파일이 수두룩했다. 

보니까 csv 파일만으론 3D Slicer에 적용이 안 되더라  
선배님께 여쭤봤더니 사용할 수 있도록 decoding하는 코드를  
미리 짜놓으셨다고 한다.

코드 보면 진짜 뭐가 뭔지 하나도 모르겠더라.  
석박사 따려면 이정도는 해야하는구나... 하며  
벽 느꼈다.

여튼 난 영상만 찍으면 되니까 ㅎㅎ  
csv를 fcsv 파일과 json 파일로 변환해서  
3D Slice에 정상적으로 사용될 수 있도록 준비하였다.

## 3D Slice
처음으로 의료 프로그램을 다뤄보았다.  

되게 신기했던 점이 있었는데,  
CT 촬영한 파일은 일반적인 이미지 파일이 아니라   
특별한 확장자를 사용한다는 점이었다.  

프로그램에 적용시키면 어디서도 열 수 없는 CT 파일을  
정상적으로 읽는 게 가능했고, 시점을 이동시킬 수도 있었다.  

선배님 덕에 변환했던 fcsv와 json 파일을 적용시키면  
CT 자료에서 nerve와 vessel로 판단되는 좌표에  
자동으로 marking 되었다.

시점을 옮겨가며 올바른 좌표에 마킹되어 있는지  
샅샅이 뒤져보고, 뭔가 좌표값이 잘 이어지다가 끊긴다던가  
아니면 있어야 할 것 같은 곳에 좌표값이 없다던가 싶은 지점은
그 지점을 기록하고 capture하였다.

단순 노가다 작업이라 여기에서 시간이 좀 많이 걸렸다.

## Video Capture
이것도 진짜 몇 번을 찍다 말다 했다.  
최대한 깔끔하게 찍으려고 컴퓨터 배경화면도  
학교 로고 담기게끔 새로 배경 만들어서 적용시켰고  
마우스 포인터도 삐끗하는 지점 하나 없도록  
성심성의껏 열심히 찍었다.

CT 자료를 3D로 변환하는 기능을 소개했고    
nerve와 vessel 좌표를 어떻게 표시하는지  
그리고 키보드 단축키로는 어떤 게 있는지도 소개했다.

간단한 업무인 것 같지만 이 업무를 위해 거의 하루를 다 썼었던 것 같다.
